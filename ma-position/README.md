# Ma position

Montre votre position sur une carte et suit le marqueur quand elle change. Affiche la précision et l’heure de la dernière position reçue.

## Exécution

Une page HTML, une feuille de style, un script. Rien d’autre : pas de dépendance,
pas d’outil de construction, pas de suivi. Les données saisies restent dans le
navigateur.
