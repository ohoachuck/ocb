# DomainRadar

Cherche si un nom de domaine est libre : un radical est testé sur les extensions courantes, un domaine complet est vérifié directement.

## Exécution

Une page HTML, une feuille de style, un script. Rien d’autre : pas de dépendance,
pas d’outil de construction, pas de suivi. Les données saisies restent dans le
navigateur.
