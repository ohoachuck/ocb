# Simulateur de prêt

Calcule une mensualité à partir du montant emprunté, du taux d’intérêt, du taux d’assurance et de la durée, puis dresse l’échéancier complet.

![Capture](shots/1.jpg)

## Exécution

Une page HTML, une feuille de style, un script. Rien d’autre : pas de dépendance,
pas d’outil de construction, pas de suivi. Les données saisies restent dans le
navigateur.
